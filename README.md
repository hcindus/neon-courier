# ⚡ NEON COURIER
**Fleet Racing Game** — DataWing-inspired courier racing

---

## 🎮 Play Now

Open `index.html` in a browser:
```bash
# From workspace root:
python3 -m http.server 8080 --directory projects/neon-courier
# Then visit: http://localhost:8080
```

Or open directly: `projects/neon-courier/index.html`

## ⚡ Quick Start

### Desktop Controls
- ← → **Arrow keys** — Steer left/right
- ↑ **Up Arrow** or **Space** — Boost

### Mobile Controls
- **Left side** — Steer left
- **Right side** — Steer right  
- **Center** — Boost

---

## 🎯 Gameplay

**You are a NET RUNNER** — Deliver messages through the Neon Wire.

### Collectibles
| Item | Points | Effect |
|------|--------|--------|
| 🔷 Data Packet | +100 | Standard collectible |
| 🔶 Encrypted Cache | +500 | +20% boost energy |
| 🔶 Fragment | +50 | Small token |

### Obstacles
| Object | Hit Effect |
|--------|------------|
| 🔴 Firewall Node | -50 points, speed drops |

### Boost System
- **Hold Space/Up** to boost (2x speed)
- **Drains energy** while active
- **Regenerates** when not boosting
- **Golden caches** refill boost
